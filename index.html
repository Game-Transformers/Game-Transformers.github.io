THE SYSTEM

The game is not the prompt.
The game is the evolving state.

Game Transformers turns a starting idea into a live decision system. Human direction establishes intent. Orchestration expands and maintains the run. Player behaviour changes what exists, what becomes possible and what gets generated next.

01 / DIRECT

Set the tension.

Choose collaborative, adversarial or mixed play. Seed the lure, principal characters, constraints and desired pressure.

03 / TRANSFORM

Make decisions matter.

Interactions alter alliances, resources, goals and future media. The next scene follows from the run — not a fixed script.

HOW A MATCH WORKS

One seed.
A run that keeps becoming.

Each phase changes the state available to the next one. The loop continues until the run reaches its completion condition.

01
HUMAN LEAD

Frame the game.

Define the mode, lure, goal, boundaries and principal characters. Human intent remains visible at the top of the run.

INTERFACE ARCHITECTURE

BCI can join the loop.
It never owns it.

A disappearing headset vendor should never be able to stop the game. Every device or modality passes through the same input adapter and becomes a normalized intent with confidence, time and source.

That makes hardware an integration layer — not a blocker, not a product dependency.
